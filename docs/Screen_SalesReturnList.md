# Screen: Sales Returns

## Purpose
The **Sales Returns Screen** lists all refunds/returns processed from customers.

## Widgets

- **Customer Filter**: Filter by customer.
- **Date Filter**: Filter by date range.
- **List**: Cards showing:
  - Return Bill Number
  - Date
  - Total Refund Amount

## Interactions

- **Tap Card**: View details.
- **Tap + Button**: Create new return.

# Screen: Thermal Printer (Legacy)

## Purpose
The **Thermal Printer Screen** is a dedicated interface for managing Bluetooth thermal printers. *Note: This functionality is largely superseded by the broader Printer Configuration screen but may exist for specific legacy support.*

## Widgets

- **Device List**: List of available Bluetooth devices.
- **Refresh Action**: AppBar button to rescan devices.
- **Auto Cut Toggle**: Switch for enabling auto-cut.
- **Print Test Receipt**: Button to test connectivity.

## Interactions

- **Scan**: Tap refresh to find devices.
- **Connect**: Tap a device to select and connect.
- **Test**: Send a test print command.

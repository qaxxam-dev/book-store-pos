# Screen: Distributor Entry (Add/Edit)

## Purpose
The **Distributor Entry Screen** manages distributor profiles.

## Widgets

- **Form Fields**:
  - **Name**: Distributor/Company Name.
  - **Phone**: Contact number.
- **Save Button**: Commits changes.

## Interactions

- **Save**: Creates or updates distributor record.

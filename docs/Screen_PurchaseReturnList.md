# Screen: Purchase Return History

## Purpose
The **Purchase Return History Screen** lists all returns made to distributors.

## Widgets

- **Distributor Filter**: Filter list by distributor.
- **Date Range Filter**: Filter by start and end dates.
- **Return List**: Cards displaying:
  - Distributor Name
  - Original Bill Number
  - Return Date
  - Total Returned Quantity (in orange)

## Interactions

- **Tap Return**: Opens `PurchaseReturnDetailsScreen` (Viewer) to see the full record.
- **Tap + Button**: Navigate to `PurchaseReturnEntryScreen` to create a new return.

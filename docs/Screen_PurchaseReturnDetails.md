# Screen: Purchase Return Details (Viewer)

## Purpose
The **Purchase Return Details Screen** (Viewer) displays the record of a completed return.

## Widgets

- **Return Info**: Return Bill Number (if applicable), Date.
- **Original Purchase Info**: Link to view the original purchase bill.
- **Distributor Info**: Name and Balance.
- **Items Table**: List of items returned and their refund values.
- **Financials**: Total Refund Amount.

## Interactions

- **View Original**: Tap **View Original Purchase** to jump to that bill's details.
- **Print/Share**: Generate return receipt.
- **Delete**:
  - Reverts the return (Increases stock, Re-charges distributor).
  - Prompts for confirmation.
